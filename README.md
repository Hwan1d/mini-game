# 🎮 미니게임 프로젝트

이 프로젝트는 브라우저에서 즐길 수 있는 **2048 웹 게임**과 터미널에서 실행되는 **CLI 미니게임 에이전트**로 구성되어 있습니다.

---

## 📁 주요 구성 파일

- **`index.html`**: 토스(Toss) 디자인 스타일의 파스텔톤 2048 웹 미니게임
- **`main.py`**: 터미널 메뉴를 제공하는 'Hwan1d 미니게임 에이전트' (CLI 숫자 맞추기 게임 내장)

---

## 🕹️ 1. 웹 2048 게임 (`index.html`)

토스 특유의 깔끔하고 세련된 카드 UI와 화사한 파스텔톤 컬러 팔레트를 적용한 2048 웹 게임입니다.

### ✨ 주요 특징
- **파스텔톤 UI**: 숫자(2 ~ 2048)마다 차별화된 파스텔톤 배경색과 부드러운 라운드 카드 디자인
- **부드러운 애니메이션**: 타일 생성 시 부드럽게 확대되는 효과 및 병합 시 통통 튀는 스프링 트랜지션(`cubic-bezier`)
- **실시간 점수 및 피드백**: 점수 획득 시 `+점수` 팝업 및 숫자 확대 효과
- **게임 오버 처리**: 더 이상 움직일 수 없을 때 블러 오버레이와 함께 최종 점수 안내 및 재도전 버튼 제공
- **다양한 조작 방식**:
  - 키보드 방향키 (`↑`, `↓`, `←`, `→`) 또는 `W`, `A`, `S`, `D` 키
  - 상단 텍스트 입력칸을 통한 명령어 입력 (`상`/`하`/`좌`/`우`, `W`/`A`/`S`/`D`, `R`: 재시작)

### 🚀 실행 방법
- 별도의 웹 서버나 설치 없이, 웹 브라우저(Chrome, Safari 등)에서 [index.html](file:///Users/hwan1d/Desktop/DCO/dir1/index.html) 파일을 직접 더블 클릭하여 열면 바로 플레이할 수 있습니다.

---

## 💻 2. CLI 미니게임 에이전트 (`main.py`)

터미널 환경에서 가볍게 즐길 수 있는 대화형 미니게임 프로그램입니다.

### ✨ 주요 특징
- **메뉴 인터페이스**: `Hwan1d 미니게임 에이전트` 전용 터미널 메뉴 제공
- **숫자 맞추기 게임**: 1부터 100 사이의 무작위 숫자를 10번의 기회 안에 맞추는 업/다운(UP/DOWN) 게임
- **안전한 입력 처리**: 잘못된 입력 처리 및 언제든지 `q`를 눌러 포기하거나 `0`을 눌러 종료 가능

### 🚀 실행 방법
터미널에서 아래 명령어를 실행합니다:

```bash
python3 main.py
```

메뉴 화면에서 원하는 번호를 입력합니다:
- `1`: CLI 숫자 맞추기 게임 시작
- `0`: 에이전트 종료
